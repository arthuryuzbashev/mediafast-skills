# MediaFast skills

Agent skills for Reddit marketing with the [MediaFast](https://www.mediafa.st) MCP server.

```bash
npx skills add arthuryuzbashev/mediafast-skills
```

## Skills

- `reddit-marketing`: finds subreddits where you can promote your product, drafts posts in the format each one accepts, shows where to comment and what to say, and builds a daily plan.

Needs a MediaFast account (sign in with OAuth or an API key), see the setup section in [skills/reddit-marketing/SKILL.md](skills/reddit-marketing/SKILL.md).
